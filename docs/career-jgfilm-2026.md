## 1. 운영 어드민 `jgfilm-admin` (2026.03 ~ 운영 중)

수기·스프레드시트·네이버 판매자센터로 돌아가던 제작 운영을 하나의 시스템으로 옮겼다. 06.08 정식 운영 시작.

### 1-1. 스택·구조
- FE: React 19 + Vite + TypeScript + Tailwind + React Query + Zustand. TipTap 리치 에디터, FullCalendar, dnd-kit, hls.js, ApexCharts.
- BE: Spring Boot 3.4 + Java 21 + JPA + MySQL + Flyway(`ddl-auto: validate`) + Spring Security(JWT) + AWS SDK(R2 S3 호환).
- 보조: Node 스케줄러(네이버 동기화·데일리 리포트) · Cloudflare Worker(ZIP 직결) · Pages Functions(영상 서울 전달).
- 인프라: AWS EC2(서울) + Docker Compose 블루-그린 · Cloudflare Pages/R2/CDN.

### 1-2. 핵심 도메인 (초기 구축 03~05)
